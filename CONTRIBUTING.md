# Contributing

Thanks for helping. This is a small, personal project, so keep changes small and easy to review.

## Reporting a problem

Open an issue and include:

- What you were doing, and what happened instead
- The company, role title, and posting link, if it is about a job
- A screenshot, if it helps

Do not include personal details, resumes, API keys, or private links.

## Suggesting a board or feature

Open an issue first and describe the board or feature in plain words. Please do not open a large pull request without an issue, because the board lists in `app.js` and `fetch_jobs.py` need to stay in sync.

## If you do open a pull request

- Keep it to one change.
- Do not change the snapshot data in `jobs.json` by hand. That file is built by the workflow.
- Do not add tracking, signup, or a server. The site is meant to stay client-side only.
- Check that the site still loads and that the change does not break the existing filters.

There is no promise that every suggestion will be merged.
